# PLC 側 I/O 抽象層（TWIN_MODE 切替）

ロジック層は実 I/O（X/Y）を直接触らず、内部リレー経由にする。
TWIN_MODE 1 ビットで「実センサ/実出力」と「仮想センサ/仮想出力（DM ブロック）」を切り替える。
本番導入時は TWIN_MODE を OFF にするだけで、ロジック層は無変更。

```
[I/O 層]
  TWIN_MODE=OFF : X000〜 → MR100〜 (実センサ)      / MR200〜 → Y000〜 (実出力)
  TWIN_MODE=ON  : DM1100.0〜 → MR100〜 (仮想センサ) / MR200〜 → DM1000.0〜 (仮想出力)
[ロジック層]
  MR100〜 / MR200〜 だけを見て書く（本番そのまま）
```

## 固定アドレス（Twin Core と共有）

| 方向 | キーエンス | 三菱 iQ-R | 内容 |
|---|---|---|---|
| PLC → PC | DM1000〜1063 | D1000〜1063 | 仮想出力ビット（word 0〜3）、監視数値・軸目標（word 4〜63） |
| PC → PLC | DM1100〜1163 | D1100〜1163 | 仮想センサビット（word 0〜3）、軸現在位置・エンコーダ（word 4〜63） |

YAML 側の `tags` でビット・ワードに名前を付ける。`bit: "0.2"` は word 0 の bit 2 = DM1000.2（出力側）/ DM1100.2（入力側）。

ワード割付の推奨（demo_line.yaml と同じ）

| word | PLC → PC (out) | PC → PLC (in) |
|---|---|---|
| 0〜3 | 仮想出力 64 点 | 仮想センサ 64 点 |
| 10,11 | 軸1 目標位置 (s32) | 軸1 現在位置 (s32) |
| 12〜19 | 監視数値（カウンタ、ステップ、周波数指令…） | 予備 |
| 20,21 | 予備 | エンコーダ (u32) |

## キーエンス KV-8000 / KV-Nano（ニモニック）

```
; ===== I/O 層 =====  TWIN_MODE = MR000
; --- 入力: 実センサ or 仮想センサ -> MR100〜MR315 (4ワード = 64点) ---
LDB MR000
BMOV X000 MR100 #4        ; 実機: X000〜 を 4 ワード分 MR100〜 へ
LD  MR000
BMOV DM1100 MR100 #4      ; ツイン: DM1100〜1103 を MR100〜 へ

; --- 出力: MR200〜MR415 (4ワード = 64点) -> 実出力 or 仮想出力 ---
LDB MR000
BMOV MR200 Y000 #4        ; 実機: MR200〜 を Y000〜 へ
LD  MR000
BMOV MR200 DM1000 #4      ; ツイン: MR200〜 を DM1000〜1003 へ

; --- 軸 (位置決めユニット KV-XH 等を使う場合) ---
; ツイン時は DM1010/1011 に目標位置、MR203 に起動を書き、
; 現在位置は DM1110/1111、BUSY/INPOS は MR104/MR105 から読む。
; 実機時はユニットバッファ ↔ 同じ MR/DM を MOV/BMOV で写す (ユニット依存)。

; ===== ロジック層 (本番そのまま) =====
LD  MR102                 ; PE1
AND MR101                 ; CYL1_HOME
OUT MR201                 ; CYL1_EXT ...
```

- ビット番号対応: `MR100` = MR ch1 bit00。DM1100.0 → MR100、DM1100.15 → MR115、DM1101.0 → MR200。
- 上位リンク通信は `[ユニット設定]-[Ethernet]-[上位リンク通信 ポート 8501]` を有効にする。
- KV-Nano は Ethernet 対応機種（KV-N**E** 系 / Ethernet ユニット）のみ。

## 三菱 MELSEC iQ-R（ニモニック）

```
; ===== I/O 層 =====  TWIN_MODE = M0
; --- 入力: X0〜X3F (4ワード) -> M100〜 / D1100〜 -> M100〜 ---
LDI M0
BMOV K4X0 K4M100 K4       ; 実機
LD  M0
BMOV D1100 K4M100 K4      ; ツイン

; --- 出力: M200〜 -> Y0〜 / D1000〜 ---
LDI M0
BMOV K4M200 K4Y0 K4       ; 実機
LD  M0
BMOV K4M200 D1000 K4      ; ツイン

; 軸 (RD77 等): ツイン時は D1010/1011 (目標), M203 (起動) / D1110/1111 (現在位置), M104/M105 (BUSY/INPOS)
```

- SLMP 設定: `[ユニットパラメータ]-[外部機器構成]` で「SLMP接続機器」を追加（TCP、ポート 5000 など、通信データコード = バイナリ）。
- ビットデバイス（M/X/Y）をワード単位で読むため、先頭番号は 16 の倍数にする（M0, M16, M32…）。

## カメラ追従排出のラダー（考え方・KV 表記）

デモ（`configs/demo_line.yaml`）の割付: CAM_DONE=DM1100.6、CAM_ACK=DM1000.5、NG 個数=DM1130、
(X,Y)=DM1132/1133, 1134/1135…、撮像時エンコーダ=DM1122(32bit)、現在エンコーダ=DM1120(32bit)、BLOW1〜4=DM1002.0〜.3。

```
; 結果受取り (CAM_DONE 立上り) -> 追従テーブル (DM2000〜, 1 件 6 ワード: X, Y, ENC(2), 有効, 予備) へ登録
LDP MR106                    ; CAM_DONE (DM1100.6 を MR へ写した先)
FOR DM1130                   ; NG 個数ぶん
  ... 空きスロットに X, Y, ENC をコピー、有効=1 ...
NEXT
OUT MR205                    ; CAM_ACK (1 スキャン)

; 追従 (毎スキャン): 位置 = 600 + X + (ENC_NOW - ENC) / 10
; 位置 >= 1200 - 15 なら ノズル = Y / 75 を 100ms ON、スロットを無効化
```

要点: エンコーダ差分で追従するのでコンベヤの加減速・停止があっても位置がずれない。
ブロー立上り遅れは先行量（LEAD）、ノズル間隔・連数は YAML の `airblow` と同じ値を PLC 定数にする。

## タッチパネル（VT5 / GOT2000）

PLC 直結のため、ツイン側の作業はゼロ。TP が触るデバイスはロジック層（MR/M/DM/D）なので、
TWIN_MODE の ON/OFF に関係なく同じ画面で操作できる。TWIN_MODE 自体を TP のスイッチに割り付けておくと便利。

## 実機側に残る注意

- 実機 X/Y は入出力ユニットが毎スキャン上書きするため、通信で書いても戻される → 必ず内部リレー経由にする。
- 位置決めユニットはアンプ未接続だとエラーになる機種がある。DM/D による軸インターフェース化（上記）で回避する。
- TWIN_MODE を ON のまま実機に出力が出ないように、安全回路（非常停止・出力許可）は I/O 層より上流に置く。
